# Contract 目录规范

> 本目录是其他所有项目的契约目录，定义系统间交互的接口规范。

## 修改规则

1. **互斥修改**
   - 修改 `api/`、`fe/`、`cli/` 时，禁止同时修改 `contract/`
   - 如需同步修改契约，应先完成 contract 修改并提交，再单独修改其他模块

2. **前置阅读**
   - 修改契约前，必须认真阅读 `docs/product/` 下的产品文档
   - 确保理解业务需求和设计意图后再进行契约修改

3. **变更存档**
   - 修改已存在的契约时，必须在 `changes/` 目录下保留修改存档
   - 存档文件命名格式：`YYYYMMDD-<契约名>-<简短描述>.md`

## 目录结构

```
contract/
├── aimp.schema        # AIMP 核心契约定义
├── changes/           # 契约变更存档
└── AGENTS.md          # 本文件
```
